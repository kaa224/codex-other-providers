# Codex Desktop на Windows только через Polza AI

Эта инструкция предназначена для пользователя, у которого:

- есть бесплатный аккаунт ChatGPT;
- есть аккаунт Polza AI и API-ключ;
- Windows 10 или Windows 11.

После настройки вход в приложение выполняется через бесплатный аккаунт ChatGPT, но модельные запросы Codex отправляются через Polza AI. Расходы и лимиты определяются аккаунтом Polza, а не бесплатным тарифом ChatGPT.

## 1. Установите Codex Desktop

Откройте PowerShell и выполните официальную команду установки приложения из Microsoft Store:

```powershell
winget install --id 9PLM9XGG6VKS -s msstore
```

Или установите приложение по [официальной странице ChatGPT для Windows](https://learn.chatgpt.com/docs/app/windows).

Запустите приложение и войдите в свой бесплатный аккаунт ChatGPT. После первого запуска полностью закройте приложение.

## 2. Скачайте установщик Polza

1. Откройте [репозиторий codex-other-providers](https://github.com/kaa224/codex-other-providers).
2. Нажмите **Code → Download ZIP**.
3. Распакуйте ZIP, например в папку `Загрузки`.
4. Откройте распакованную папку, щёлкните по пустому месту правой кнопкой и выберите **Открыть в терминале**.

## 3. Запустите настройку

В PowerShell выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Install-PolzaOnly.ps1
```

Установщик попросит:

1. API-ключ Polza — ввод скрытый, символы не отображаются.
2. ID модели — установщик покажет доступные модели с поддержкой изображений. Скопируйте подходящий ID целиком.

В конце должна появиться зелёная надпись `Polza-only setup completed successfully`.

## 4. Запустите Codex

Полностью закройте PowerShell и запустите Codex Desktop обычным ярлыком. Создайте новый чат. В списке моделей будут модели Polza с поддержкой текста и изображений.

## Проверка

В новом PowerShell можно выполнить:

```powershell
codex debug models
```

Также проверьте файл `%USERPROFILE%\.codex\polza-install.log`. В нём нет API-ключа.

## Важно

- Не отправляйте API-ключ в мессенджерах и не вставляйте его в команды.
- Запросы, файлы и скриншоты передаются Polza AI и выбранному через неё поставщику модели.
- Каталог моделей обновляется повторным запуском установщика.
- Резервная копия прежней конфигурации сохраняется как `%USERPROFILE%\.codex\config.before-polza.*.toml`.

## Если не работает

Запустите:

```powershell
& "$env:USERPROFILE\.codex\Test-PolzaSetup.ps1"
```

Если появляется ошибка авторизации, создайте новый API-ключ в Polza и повторно запустите установщик.
