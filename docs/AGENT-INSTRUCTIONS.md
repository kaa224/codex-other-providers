# Инструкция для агентских приложений

Эту страницу можно передать Codex, Claude Code, Cursor или другому агенту вместе со ссылкой на репозиторий.

## Готовый запрос агенту

> Установи переключатель провайдеров Codex Desktop из этого репозитория. Сначала создай резервную копию `~/.codex/config.toml`. Не печатай и не записывай API-ключ в репозиторий, логи или TOML; сохрани его в пользовательской переменной среды. Определи путь рабочего стола через Windows API, создай два ярлыка и проверь оба переключения с `-NoRestart`. Не закрывай Codex во время проверки. В конце оставь выбранный мной профиль активным и покажи результаты диагностики.

## Требуемая последовательность

1. Проверить Windows, наличие Codex Desktop и `~/.codex/config.toml`.
2. Получить у пользователя base URL, имя переменной ключа, модель и необязательный каталог.
3. Запустить `scripts/Install-CodexProviderSwitcher.ps1`; установщик сам использует скрытый ввод ключа.
4. Никогда не передавать секрет в командной строке или сообщении агенту.
5. Выполнить переключатель для `Other` и `OpenAI` с `-NoRestart`.
6. Запустить `scripts/Test-CodexProviderSetup.ps1`.
7. Не запускать обычный ярлык до сообщения пользователю: он закроет текущий Codex.

## Критерии готовности

- TOML синтаксически читается Codex;
- блок стороннего провайдера существует ровно один раз;
- API-ключ отсутствует в файлах проекта и `config.toml`;
- оба ярлыка существуют;
- журнал фиксирует оба тестовых переключения;
- резервная копия создана.
