# Безопасность

- Никогда не добавляйте API-ключи, токены, `auth.json` или содержимое `~/.codex` в Git.
- Храните ключ в пользовательской переменной среды, указанной через `env_key`.
- Помните: запросы, файлы и скриншоты при выборе стороннего провайдера передаются этому провайдеру и регулируются его условиями.
- Проверяйте URL провайдера и используйте только HTTPS.
- Перед установкой изучите скрипты. Они меняют `~/.codex/config.toml`, создают ярлыки и перезапускают Codex.
- Для каждого компьютера используйте отдельный ключ, если провайдер это позволяет.
- При утечке немедленно отзовите ключ у провайдера и создайте новый.
