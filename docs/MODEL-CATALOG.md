# Каталог моделей

`model_catalog_json` заставляет Codex использовать указанный JSON-каталог при запуске. Формат зависит от версии Codex, поэтому самый надёжный вариант — получить каталог у провайдера или экспортировать каталог из совместимой установленной версии.

Минимальная структура обычно содержит объект `models` с массивом описаний:

```json
{
  "models": [
    {
      "slug": "provider-model-id",
      "display_name": "Readable model name",
      "description": "Model description",
      "visibility": "list",
      "supported_in_api": true
    }
  ]
}
```

Для скриншотов выбирайте модели, у которых провайдер явно заявляет поддержку image/vision input. Наличие модели в списке не доказывает поддержку изображений или доступность на вашем тарифе.

Проверьте JSON перед установкой:

```powershell
Get-Content .\models.json -Raw | ConvertFrom-Json | Out-Null
```

Не публикуйте каталог, если условия провайдера запрещают его распространение.
